# 05 失误率：同样 3 次失误，意义可能不同

## 这个指标想解决什么问题

失误数是总量。它没有告诉你一个球员承担了多少进攻责任。

同样 3 次失误：

- 如果来自一个使用率很高的持球核心，可能是大量处理球的副产品；
- 如果来自一个几乎只接球投篮的角色球员，问题就更严重。

失误率想解决的就是这个比较问题。

## 这个数据怎么看？

左图是球员 TOV% 密度图，红线是 Austin Reaves。右图把“每 36 分钟失误数”和“TOV%”放在一起。这样能看出一个关键区别：**失误数高，不一定代表失误率高；失误率高，才说明机会被浪费的比例高。**

在 500+ 分钟球员里，估算 TOV% 的中位数约 **12.0%**。如果一个球员每 36 分钟失误多，但使用率也高、处理球任务重，他可能只是承担了更多风险。反过来，如果一个低使用率角色球员 TOV% 很高，就更值得警惕，因为他本来没有太多机会可浪费。

Austin Reaves 的估算 TOV% 约 **14.0%**，高于样本中位数。这并不能直接说明他“不好”，因为他同时有较高使用率和持球责任；但它提醒我们：评价他进攻时，不能只看 TS% 或三分，还要把失误成本算进去。

读右图时，右上角最危险：既有不少失误数，又在自己的使用机会里占比较高。只在右侧但不高，可能是高持球职责；只在上侧但不右，可能是低机会角色的高浪费率。

## 直觉解释

失误率不是问“你失误了几次”，而是问：

> 在你可能结束进攻的机会里，有多少比例变成了失误？

这比失误数更接近“浪费机会的频率”。

## 公式

常见球员/球队估算：

$$
TOV\% = \frac{TOV}{FGA + 0.44 \times FTA + TOV}
$$

分母近似表示投篮、罚球和失误这些回合终结机会。

## 常见误读

**误读：助攻多的球员失误多，所以不稳。**

要看角色。高传球量和高持球量通常带来更高失误数。更公平的读法是结合：

- 使用率；
- 助攻率；
- 失误率；
- 球队进攻效率；
- 比赛情境和对手防守强度。


## 读图结论

图里横轴是每 36 分钟失误数，纵轴是估算失误率。真正需要警惕的是右上角：失误频率高，而且在可使用机会中占比也高。只有失误数高，不一定等于处理球差。
