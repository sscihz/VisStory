# 前言：用数据思维看 NBA

很多球迷第一次接触现代篮球数据时，会觉得它们像一堆缩写：USG%、TS%、eFG%、TOV%、ORB%、PACE、ORTG。真正的问题不是公式复杂，而是这些指标没有被翻译成篮球语言。

这套教材的核心假设是：

> 好的篮球数据不是替代看球，而是帮助你更准确地描述你已经在比赛里看到的东西。

比如“某球员很能抡”可以被拆成两个问题：

1. 他在场时，球队多少进攻回合由他结束？
2. 他结束这些回合时，效率有没有被维持住？

第一个问题接近 **使用率**，第二个问题接近 **真实命中率**、**每 100 回合得分** 或更复杂的效率指标。

## 这本教材不做什么

- 不把复杂指标包装成万能答案。
- 不把球员价值简化成单一排名。
- 不假装公开数据能完整替代战术、伤病、角色、对位和教练安排。

## 这本教材要做什么

每章都围绕一个基础概念：

1. 它想解决什么篮球问题？
2. 直觉上该怎么理解？
3. 公式是什么？
4. 常见误读是什么？
5. 真实数据画出来长什么样？
6. 读者如何用代码复现？

如果你能读懂“36 分钟出手 8 次三分”“使用率 30%”“失误率 12%”“进攻篮板率 30%”这些数字背后的篮球含义，你就已经进入了现代篮球分析的门口。

## 数据说明

教材代码优先读取 `suren-nba/surennba_stats` 公开球员统计表。该项目对接 NBA 官网 API 与 pbpstats 数据接口，并输出适合分析的 CSV、Parquet、Excel 数据。

为了让教材能稳定构建，本仓库也保留了小型内置样例。样例只用于离线兜底；正式图表应以真实数据为准。
